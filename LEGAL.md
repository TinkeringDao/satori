## 3. Non-Circumvention of Technological Protection Measures (TPMs)

This software **does not** circumvent, bypass, strip, decrypt, or disable any effective technological protection measure, cryptographic signature check, DRM system, bootloader lock, SELinux policy, or access control mechanism within the meaning of **Article 6 of Directive 2001/29/EC (InfoSoc Directive)** or **17 U.S.C. § 1201(a) (DMCA)**:

- **Standard Android Sandbox:** Satori runs strictly as a standard unprivileged Android user-space application (`minSdk = 31`, `targetSdk = 35`) within the unmodified Android application sandbox.
- **No Root or Exploit Chains:** Satori requires no root access, no bootloader unlocking, no system partition modification, and no privilege escalation.
- **Explicit User Authorization:** Optional binding of the hardware power-key double-press (`docs/QUICK_KEY.md`) uses the official Android Debug Bridge (`adb shell settings put ...`) executed explicitly by the physical owner of the device over an authenticated USB debugging session.

This repository contains **100% original source code** and permissively licensed open-source components:
